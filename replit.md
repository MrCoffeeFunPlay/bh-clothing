# BH Clothing storefront

This project is a frontend-only React, TypeScript, and Vite ecommerce storefront starter.

## Run

- The main Replit workflow is `Start application`.
- It runs `npm run dev`.
- Vite serves the app on `0.0.0.0:5000` with proxied hosts enabled.
- Run `npm run build` for the production type-check and bundle.

## Current scope

The catalogue is live in Supabase and managed by approved admins in the owner area (`#admin`); see `LAUNCH_SETUP.md`.
Payments, checkout, orders, stock and customer accounts are not connected yet.
