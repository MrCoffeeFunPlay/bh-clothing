# BH Clothing storefront

This project is a frontend-only React, TypeScript, and Vite ecommerce storefront starter.

## Run

- The main Replit workflow is `Start application`.
- It runs `npm run dev`.
- Vite serves the app on `0.0.0.0:5000` with proxied hosts enabled.
- Run `npm run build` for the production type-check and bundle.

## Current scope

The storefront uses the original BH product images from `public/catalog`. Prices and inventory are intentionally unpublished until the owner confirms them. Payments, authentication, checkout, shipping, persistence, databases, and real customer accounts are not connected yet.
